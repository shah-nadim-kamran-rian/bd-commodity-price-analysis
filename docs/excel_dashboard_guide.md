# Excel dashboard guide

The dashboard is generated by `src/03_build_excel_dashboard.py`, so it always matches the latest SQL results. This page covers what is in the workbook, how to use it and how to extend it by hand.

## Build it

```bash
python src/01_clean_data.py
python src/02_run_queries.py
python src/03_build_excel_dashboard.py
```

The file is saved to `dashboard/commodity_price_dashboard.xlsx`. Open it in Excel. Formulas calculate when the file opens; if any cell shows 0 where it shouldn't, press Ctrl+Alt+F9 to force a full recalculation.

## Sheets

| Sheet | What it shows |
|---|---|
| Dashboard | KPI tiles, three charts and two market heatmaps |
| Explorer | Pick a commodity and see prices by market and stock level, all calculated with formulas |
| q1_commodity to q8_weather_harvest | The output of each SQL query, unchanged |
| Data | The clean dataset as an Excel table |
| Notes | Definitions and limitations |

## Dashboard

- **KPI tiles.** Record count, number of commodities and the number of price anomalies come straight from the Data sheet (COUNTA, SUMPRODUCT/COUNTIF and SUM). The least predictable commodity and the biggest low-stock markup use INDEX and MATCH on the SQL result sheets.
- **Price spread by commodity.** CV % from q1. A higher bar means the price is harder to budget for.
- **Low stock vs high stock price gap.** From q4. How much more the average purchase costs when stock is low.
- **Price index by stock level.** From q7, split by the price anomaly flag. 100 is the commodity's average price. If the blue bars (no anomaly) still rise as stock falls, the low-stock premium is broad-based and not just a few extreme purchases.
- **Heatmaps.** CV % and the low vs high gap for every market and commodity, coloured green (low) to red (high). The second heatmap rests on small groups in places, so check n_low and n_high on q5_market_premium before quoting a single cell.

## Explorer

Choose a commodity from the yellow dropdown in C4. Everything below it updates:

| Column | How it is calculated |
|---|---|
| Low, Medium, High | AVERAGEIFS on price by commodity, market and stock level |
| Rows | COUNTIFS |
| Avg price | AVERAGEIFS by commodity and market |
| CV % | Standard deviation from SUMPRODUCT, divided by the average |
| Low vs high | Low price / High price - 1 |
| Anomaly share | Average of the 0/1 anomaly flag, shown as a percentage |

The table has a colour scale so the most expensive market and stock level combination stands out, and the chart title follows the dropdown.

## Adding a pivot table (optional)

XlsxWriter can't create pivot tables, but the Data sheet is ready for one:

1. Click any cell in the table on the Data sheet.
2. **Insert > PivotTable > New Worksheet**.
3. Rows: market. Columns: stock_level. Values: purchase_price, summarised by Average.
4. With the pivot selected, insert a slicer for commodity and season.
5. Drag the stock_level headers into the order Low, Medium, High.

Save the file under a new name if you do this, because running the script again overwrites the original.
